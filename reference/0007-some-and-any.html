Quick reference · Lesson 14

Some and any

Как сказать, что что-то есть, спросить об этом и сообщить, чего нет.

Talk about amounts without an exact number.

Some: что-то есть; точное количество не называем.
Any (in questions): есть ли что-нибудь?
Not any: совсем нет.
Is/are: plural countable nouns → are; uncountable nouns → is. Some/any этого не меняют.

Three sentence jobs

Job Plural countable noun Uncountable noun
Positive statement There are some tools. There is some oil.
Neutral question Are there any tools? Is there any oil?
Negative statement There are not any tools. There is not any oil.

Choose is or are from the noun

Meaning Noun phrase Be form
One new item a tool / an engine is
Plural items some tools / any tools are
An amount some oil / any oil is

Other uncountable nouns here: water, money, gasoline, soap, equipment.

В этих значениях some и any стоят перед plural countable nouns или uncountable nouns. Для одного нового предмета используйте a/an.

Short answers stay familiar

Is there any oil? Yes, there is. / No, there is not.

Are there any tools? Yes, there are. / No, there are not.

No and not any

There is no oil. = There is not any oil.

There are no tools. = There are not any tools.

Both patterns say something is missing. Choose no + noun or not any + noun.

Само any не означает «нет». В сочетании not any отрицание создаёт not.

Understand the whole question

Is there any money for a service?

Есть ли деньги на обслуживание? Здесь any не означает «каждый».

Some does not necessarily mean a small amount. You can also say There is oil without some.

with have and need

Mia needs some oil. → Does Mia need any oil? → Mia does not need any oil.
