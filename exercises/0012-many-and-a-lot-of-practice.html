Homework · Lesson 15 · Review

Grammar review

Try each item before opening the sample answers. Mark + if your first answer matched, or - if you corrected it. Leave the mark empty when there is no visible sample.

If you get stuck, mark the item with ? and move on. We will discuss it together.

Word help

tool = инструмент; glove = перчатка; oil = масло; equipment = оборудование.

appointment = запись на определённое время; available = свободен, может помочь; soap = мыло; need = нуждаться в чём-то.

bucket = ведро; sponge = губка; owner = владелец.

Session 1

Level 1: build the noun phrase

Use a/an for one new item. Use some for more than one item or an amount. Write only the noun phrase. Use the noun reference when you need it.

Example: one / sponge → a sponge.

Example: more than one / tool → some tools.

Запишите только noun phrase. More than one = больше одного; an amount = какое-то количество.

  1. one / old / engine
  2. more than one / glove
  3. an amount / oil
Sample answers

1. an old engine

2. some gloves   3. some oil

Level 2: use am, is, or are

Write only the missing word. Use the to be block in the sentence builder.

Example: The car ______ ready. → is.

Во всех трёх предложениях нужен to be. Впишите одно слово: am, is или are.

  1. The mechanics ______ not busy.
  2. ______ the owner available?
  3. I ______ a driver.
Sample answers

1. are

2. Is   3. am

Session 2

Level 3: some or any?

Write only some or any. Use the some/any reference.

Example: There is ______ water in the bottle. → some.

В этих заданиях используйте some в positive statement, any в вопросе о наличии и после not.

  1. There is ______ oil in the garage.
  2. Are there ______ gloves in the box?
  3. There are not ______ appointments this afternoon.
Sample answers

1. some

2. any   3. any

Level 4: complete the there sentence

Write one word in each gap. Use the noun and agreement table.

Example: There are not any ______ in the box. (sponge) → sponges.

Example: There ______ some water. → is.

С countable noun в этих предложениях используйте plural form. С uncountable noun используйте is.

  1. Are there any ______ in the bag? (tool)
  2. There ______ some equipment in the garage.
  3. There are not any ______ this morning. (appointment)
Sample answers

1. tools

2. is   3. appointments

Session 3

Level 5: complete the action-verb sentence

Use have or need as shown in brackets. Fill the gaps and write the whole sentence. Use the action verb block in the sentence builder.

Example: ______ the owner ______ any oil? (have) → Does the owner have any oil?

Запишите полное предложение. После do/does и do not/does not используйте basic verb.

  1. The owner ______ some tools. (have)
  2. The mechanics ______ any new tools. (not need)
  3. ______ Mia ______ any oil? (need)
Sample answers

1. The owner has some tools.

2. The mechanics do not need any new tools.

3. Does Mia need any oil?

Level 6: build a there sentence

Use there is / there are in every item. Keep the noun form shown in the prompt and use the requested expression. Write the whole sentence. reference

Example: oil / in the garage; positive statement with some → There is some oil in the garage.

Во всех пунктах используйте there is/are. В пункте 3 добавьте короткий ответ.

  1. equipment / in the office Make a positive statement with some.
  2. gloves / in the bag Make a negative statement with not any.
  3. soap / in the bottle Make a question with any. Answer no.
Sample answers

1. There is some equipment in the office.

2. There are not any gloves in the bag.

3. Is there any soap in the bottle? No, there is not.

Level 7: mixed sentences

Write one complete sentence in English for each bold message. The other text gives the situation. You may use the references. More than one answer is sometimes possible.

Запишите по-английски только выделенную часть. Остальной текст описывает ситуацию. Сами выберите, как построить предложение.

Example: Вы говорите о своей машине. Твоя машина новая? → Is your car new?

  1. В гараже есть два ведра.
  2. Мие нужно масло?
  3. Механики не заняты.
  4. Вы ищете перчатки. Они в машине?
  5. В бутылке есть вода?
  6. У Лео нет денег.
  7. Сегодня утром нет записей.
  8. Владелец работает в гараже каждое утро.
  9. Твой брат механик?
  10. В офисе есть оборудование.
  11. У владельца есть перчатки?
  12. Вы уже говорите об оборудовании в гараже. Оборудование готово.
  13. Твоя машина не в гараже.
  14. В коробке есть губки?
  15. Лео не нужна новая машина.
Sample answers

3. The mechanics are not busy.

5. Is there any water in the bottle?

7. There are not any appointments this morning.

8. The owner works in the garage every morning.

11. Does the owner have any gloves?

1. There are two buckets in the garage.

2. Does Mia need any oil?

4. Are they in the car? / Are the gloves in the car?

6. Leo does not have any money. / Leo has no money.

9. Is your brother a mechanic?

10. There is some equipment in the office.

12. The equipment is ready. / It is ready.

13. Your car is not in the garage.

14. Are there any sponges in the box?

15. Leo does not need a new car.

These are possible answers. Other natural sentences with the same meaning are valid. Some/any can be omitted where grammatical; no appointments is also valid in item 7. Contractions are acceptable.
